# SOS-Graph-theory-
# Graph Theory — Summer of Science 2026

A structured study of graph theory covering fundamental concepts, theoretical results, algorithmic techniques, and their applications. This repository documents my learning journey through the **Summer of Science (SoS) 2026** program.

## Topics Covered

- **Graph Fundamentals:** Vertices, edges, degree, adjacency, graph types, and graph representations
- **Graph Traversal:** Breadth-First Search (BFS), Depth-First Search (DFS), connected components, and traversal trees
- **Bipartite Graphs & Matching:** Bipartite graph characterization, Hall's Matching Theorem, and matching applications
- **Graph Coloring:** Chromatic number, greedy coloring, and applications in scheduling and resource allocation
- **Paths & Connectivity:** Paths, walks, shortest paths, and connectivity in graphs
- **Shortest Path Algorithms:** BFS for unweighted graphs and Dijkstra's algorithm for weighted graphs
- **Trees & Spanning Trees:** Tree properties, spanning trees, and minimum spanning trees
- **Disjoint Set Union (DSU):** Operations, optimizations, and applications
- **Kruskal's Algorithm:** Minimum spanning tree construction and network optimization
